# Algorithms and data structures in C++

Solutions for frequency counting, circular simulation, subset-sum dynamic programming and graph traversal.

`hw1/` contains Aliens and Robots. Santa and Maze appear in the remaining source directories; their duplicate copies reflect separate exercise workspaces.

Compile each problem separately with a C++ compiler. Programs use their named `.in` and `.out` files. Some exercises use fixed limits or compiler extensions; check the problem constraints before changing input sizes. Maze uses an adjacency matrix, so its traversal scans O(V²) entries.

University algorithm assignments by Ovidiu Catalin Ghibea.
